# A Little Letter for You

A frontend-only romantic story website prototype built with React + Vite.

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open the extracted folder in VS Code.
4. Open Terminal in that folder and run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Notes
- This is a frontend prototype only. It uses sample copy and sample image URLs.
- No database, admin dashboard, authentication service, payment system, or file upload backend is connected.
- Replace the sample photos and text in `src/main.jsx` with the customer's own content later.
- The background and sample photos load from Unsplash, and fonts load from Google Fonts, so an internet connection is needed for those remote assets.
